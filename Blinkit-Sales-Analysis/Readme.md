# Blinkit Sales Analysis Dashboard | Power BI

## Project Overview
This project presents an interactive sales analysis dashboard for Blinkit, designed to visualize key business metrics and explore sales performance.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (if used in the project)

## Dashboard Preview

![Blinkit Power BI Dashboard](dashboard.png)

## Key Features
- KPI cards for important business metrics
- Sales analysis by product and category
- Interactive charts and visualizations
- Filters and slicers for exploring the data

To demonstrate Power BI dashboard design, data visualization, and business reporting skills.
